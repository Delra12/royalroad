## 2026-09-25 — clarified failure criterion

### Key insight
The user does **not** require a weak protagonist. An OP protagonist is fine. The important requirement is that the protagonist can genuinely lose/fail repeatedly.

Time-loop stories are especially strong because death can function as a real failure state without ending the narrative. Preferred failures involve being outplayed, making a wrong decision, failing an objective, losing a fight/person/opportunity, or discovering that an approach was fundamentally wrong. The best progression from a loss is information/understanding and a changed strategy, not simply more stats.

### Discussed in this search
- A Regressor’s Tale of Cultivation — strongest fit from that search; already used now.
- Purple Days — potentially strong fit; fanfic wildcard; already used now.
- Death After Death — genuine repeated failure, but early MC may be irritating; already used now.
- Dear Spellbook — mechanics fit, presentation may not; already used now.
- The Undying Immortal System — repeated failure but potentially too cultivation/crafting-grind heavy; already used now.
- DIE. RESPAWN. REPEAT. — rejected because death increasingly functions as XP/power farming rather than meaningful failure.

### Rule for future searches
Search for evidence of repeated meaningful loss/failure, not merely tags like “time loop,” “regression,” or “weak-to-strong.” A title where the MC technically dies but each death is just an optimization mechanic is not necessarily a fit.

## 2026-09-25 — first repo-backed search

### Strong candidate
- **Loopshard** by Dosei — best find this search. Male MC, ongoing with 243 chapters and frequent updates. The opening is system-apocalypse / roguelite rather than medieval politics, which is the major caveat. Strong evidence from later reviews that each death remains meaningful, relationships disappear/change across runs, builds do not let the MC instantly steamroll future loops, mysteries persist, and different loops expose different versions of characters. One review explicitly describes each loop as almost its own short story and emphasizes information/mystery plus lasting emotional loss. The MC can be reckless/dumb at points, according to critical reviews. Strong recommendation despite setting caveat.

### Considered but not recommended
- **Blessed Time** — first book does contain real mistakes, bad loops, psychological cost, and resets that erase levels/wealth/relationships. However, reviews are sharply mixed, later books move away from the time-loop premise, and some readers report deus-ex-machina/character issues. Do not prioritize unless user asks for deeper look.
- **The Menocht Loop** — starts with an OP male MC and a layered loop, but reviews repeatedly note that the actual loop is largely front-loaded and stops functioning as the core story mechanic. Poor match for the user's desire for repeated meaningful losses throughout.
- **Minute Mage** — limited resets create tactical stakes early, but multiple critical reviews say the story increasingly guarantees a solution within the reset allowance, drifts toward plot armor/power fantasy, and lacks the deeper mystery/world/character focus the user prefers.
- **The Lost Mortal's Endless Deaths** — surfaced as a new active time-loop title, but chapter titles and premise explicitly emphasize dying to gain powers and level farming. This looks too close to the exact death-as-XP pattern the user dislikes.
- **Thousandth Death's the Charm** — superficially strong fit (male MC, repeated death, mystery, changing characters), but Royal Road marks it on hiatus, so excluded under current rules.

### Search lesson
The best match may still have game/system elements, but the key distinction is whether looping changes **relationships, information, and decisions**, not merely the protagonist's permanent combat numbers.
